A classic, two-player Tic-Tac-Toe game built entirely in C++ with a command-line interface.

## Features
* **Input Validation:** Prevents out-of-bounds moves and overwriting existing plays.
* **State Detection:** Automatically detects horizontal, vertical, and diagonal win conditions, as well as ties.
* **Efficient Loop Logic:** Uses a clean `while` loop structure to manage game states and player turns without unnecessary iterations.
